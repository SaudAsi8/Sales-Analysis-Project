Sales Analysis Project



Project Overview



This project uses SQL to analyze sales data for a fictional retail store. The goal is to explore sales performance, product profitability, customer behavior, and monthly revenue.



Database Structure



The database contains five tables:



customers: Customer information and cities.



categories: Product categories.



products: Product details, prices, and costs.



orders: Order dates and statuses.



order\_items: Products and quantities included in each order.



SQL Skills Used



Database and table creation



Data insertion



INNER JOIN



GROUP BY and ORDER BY



Aggregate functions (SUM, COUNT, AVG)



Date formatting



DISTINCT



Business Analysis



The project covers:



Total revenue and profit



Total and average order value



Best-selling products



Revenue and profit by product and category



Sales by city and month



Orders by status



Top spending customers



Customer and product performance



Project Files



01\_Create\_Tables.sql – Creates the database and tables.



02\_Insert\_Data.sql – Inserts sample data.



03\_Sales\_Analysis.sql – Contains SQL queries for sales analysis.



How to Run



Run the SQL files in the following order:



01\_Create\_Tables.sql



02\_Insert\_Data.sql



03\_Sales\_Analysis.sql



Dataset



The dataset is fictional and was created for learning and practice purposes. It does not represent real business transactions.
